# TOKATLIANN · GUIDE

Автономный интерактивный `/guide/` на HTML/CSS/JavaScript. Откройте двойным кликом `index.html` в корне или `guide/index.html`. Сервер, npm и интернет для интерфейса не нужны; внешние товарные ссылки ведут на TOKATLIANN.

## Документация

- `docs/REQUIREMENTS.md` — актуальное поведение и критерии приёмки.
- `CHANGELOG.md` — история изменений и замены требований.
- `docs/BITRIX-INTEGRATION.md` — контракт данных, дефолтный товар из админки, порядок интеграции следующего этапа.
- `AGENTS.md` — краткие указатели и правила для будущих ИИ-агентов.
- `QA.md` — фактически выполненные проверки и ограничения.
- `ANALYSIS.md` — исторический анализ исходного сайта; решения поведения из первой версии заменены актуальными требованиями.

## Исходники

`guide/guide.html` — общий фрагмент без шапки/подвала. `guide/assets/guide.css` — изолированные стили; `guide.js` — последовательный контроллер; `guide-motion.js` — локальный GSAP motion и прелоадер; `guide-data.js` — данные версии 3. Фото, шрифты, SVG и GSAP хранятся локально.

`guide/index.html` — собранный preview с захваченной оболочкой сайта; `guide/index.php` — подготовленная точка входа со штатными Bitrix header/footer. Реальных запросов инфоблоков/каталога в ней нет. `preview.*` и `site-shell.css` относятся только к автономной демонстрации.

После изменения общего HTML: `python work/build_preview.py`. CSS/JS/данные применяются после обновления страницы. `work/` содержит исходники анализа и локальные fixtures, не предназначенные для production.

## Замена дефолтного товара в демо

В `guide/assets/guide-data.js` изменить `settings.defaultProductId` на существующий ключ из `products`. До завершения всех трёх шагов будет показываться этот товар. Текущая настройка демонстрационная и не утверждает реальное лидерство продаж. Для админки Bitrix предусмотрена отдельная привязка, описанная в инструкции интеграции.

Названия, фото и URL товаров взяты с сайта. Состояния, схемы и соответствие товара состоянию — тестовые. «Купить» ведёт к товару, без автоматического добавления в корзину.

## Происхождение ассетов

Логотип, социальные иконки и товарные фото — TOKATLIANN; каталог-источник сохранён в `work/source/catalog-v2.json`. Forum / PT Serif — Google Fonts, локальные лицензии в fonts/. UI-иконки Lucide Static 0.468.0 — ISC. GSAP 3.15.0 — локальная копия официального npm-пакета, сведения в vendor/README.txt. Фотография и косметические текстуры подготовлены встроенным ImageGen; назначение и промпты описаны в `docs/ASSETS.md`.

Деплой на действующий TOKATLIANN не выполняется; интеграция и проверка внутри настоящего Bitrix — следующий этап.

## GitHub Pages

Статическое демо: https://asallweb.github.io/tokatliann-guide-frontend/guide/
Репозиторий: https://github.com/asallweb/tokatliann-guide-frontend

Workflow `.github/workflows/pages.yml` публикует изменения ветки `main`. В Settings → Pages выбран источник **GitHub Actions**. Перед push после изменения разметки выполните `python work/build_preview.py`; сборка в Actions также обновляет standalone HTML.

Локальная проверка набора публикации: `python scripts/build_pages.py`. Результат — `work/pages/`: launcher, standalone GUIDE и локальные ассеты. PHP, документация, исходники анализа и fixtures не попадают на Pages. HTML и все пути остаются совместимы с двойным кликом и адресом проекта GitHub Pages.

Git сохраняет код, документацию, актуальные медиа и необходимые для пересборки `work/build_preview.py`, `work/source/shell.json`, `work/source/catalog-v2.json`. Прочие scratch-файлы и старые неиспользуемые кропы исключены через `.gitignore`. Общая лицензия на бренд и товарные медиа не предоставляется; лицензии сторонних библиотек/шрифтов сохранены рядом с ними.
